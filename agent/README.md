## 文档对应的代码版本
本项目有两条并行分支,`agent/` 下的文档**两版通用**;只有原版 API 有差异的地方单独标注:

| 分支 | Minecraft | 产物名 |
|------|-----------|--------|
| `26.2` | 26.2 | `SlimefunHelper-26.2-<mod版本>.jar` |
| `26.1` | 26.1.2 | `SlimefunHelper-26.1.2-<mod版本>.jar` |

- 类名一律使用 **mojmap 官方名**(Mojang 官方映射),不是 yarn 名
  - 例:`LocalPlayer`(yarn: `ClientPlayerEntity`)、`Level`(yarn: `World`)、`Vec3`(yarn: `Vec3d`)、`Component`(yarn: `Text`)、`Identifier`(yarn: `Identifier` / 旧 mojmap `ResourceLocation`)、`GuiGraphicsExtractor`(yarn: `DrawContext`)
- **两版有差异的原版 API**(HUD 挂载点、屏幕/聊天访问器、渲染提取与提交、实体类型常量、颜色集合等)
  汇总在 `总述.md` 的「26.1.2 与 26.2 的 API 差异」一节
- 文档与代码不一致时,**以代码为准**
