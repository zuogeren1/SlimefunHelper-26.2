# SlimefunHelper 命令系统开发速查

> 对应代码:`src/main/java/me/matl114/utils/commands/`、`src/main/java/me/matl114/commands/MainCommand.java`
> 版本:**Minecraft 26.1.2 / 26.2**(mojmap 官方名)。命令框架本身两版一致。

## 0. 核心类

| 类 | 作用 |
|---|------|
| `MainCommand` | 命令总入口:分发 `/sfh ...` 与 `/sfhelper ...`,管理 bootstrap |
| `AbstractMainCommand` | 根命令基类,内部持有一个 `ListSubCommand` 作为根节点 |
| `SubCommand` | 子命令接口;实现有 `TaskSubCommand`(叶子)、`TreeSubCommand`(容器) |
| `SubCommand.Builder` / `SubBuilder` | 子命令构建器(`.name/.helper/.arg/.post/.complete()`) |
| `CommandContext` | 命令执行体(函数式接口),由 `TaskSubCommand.executor(...)` 消费 |
| `CommandExecution` | 执行上下文(发送者、发消息、权限、执行位置/朝向/世界) |
| `ArgumentReader` | 原始参数游标(已读/未读、下标、回退) |
| `ArgumentInputStream` | 按定义顺序解析参数,提供类型安全读取 |
| `SimpleCommandArgs` | 参数表;`SimpleCommandArgs.ArgumentBuilder` 是参数 DSL |
| `ArgumentType` / `InputArgument` / `TabResult` | 参数类型、解析结果、补全结果 |

## 1. 创建根命令

```java
public class MyCmd extends AbstractMainCommand {
    public MyCmd() {
        setMainName("mycmd");
        setPermissionRequired("my.permission"); // 可选

        registerSub(SubCommand.taskBuilder()
                .name("hello")
                .helper("message.command.mycmd.hello.help")
                .arg(SimpleCommandArgs.argumentBuilder().name("name").build())
                .post(e -> e.executor(this::onHello))
                .build());
    }

    private boolean onHello(CommandExecution exec, ArgumentInputStream args, ArgumentReader reader) {
        exec.sendMessage("Hello " + args.nextNonnullString());
        return true;
    }
}
```

在 `BaseModule` 里挂上去:

```java
@Override
public void registerAll() {
    super.registerAll();
    registerCommandBootstrap(mc -> mc.registerAsCommand(new MyCmd()));
    // 或者
    // registerCommand(MyCmd::new);
    // registerAsSubCommand("mycmd", MyCmd::new);
}
```

## 2. 构建多级子命令(以 `/target calculate ...` 为例)

```java
public void bootStrapTargetCommand(MainCommand mainCommand) {
    TreeSubCommand main = mainCommand.mainBuilder().name("target").build();

    main.subBuilder(SubCommand.treeBuilder())
            .name("calculate")                       // 一级:/target calculate
            .post(m -> m.subBuilder(SubCommand.taskBuilder())
                    .name("waypoint")                // 二级:/target calculate waypoint
                    .helper("message.command.target.calculate.waypoint.help")
                    .arg(SimpleCommandArgs.argumentBuilder()
                            .name("waypoint")
                            .tabSupplier(WorldUtils::getWaypointNames)
                            .build())
                    .post(s -> s.executor(CommandContext.execute(this::onCalculateWaypoint)))
                    .complete()
                    .subBuilder(SubCommand.taskBuilder())   // 同一个父节点下再加一个叶子
                    .name("pos")
                    .helper("message.command.target.calculate.pos.help")
                    .arg(SimpleCommandArgs.argumentBuilder(MovTasks.TpaAndPosArgumentType::new)
                            .name("target")
                            .build())
                    .post(s -> s.executor(CommandContext.execute(this::onCalculatePosition)))
                    .complete())
            .complete();
}
```

要点:

- `mainCommand.mainBuilder()` 建**一级**树命令并自动注册到根;`subMainBuilder()` 则会包一层 `BridgeSubCommand`。
- `.post(...)` 在 `build()` 之后执行,用来拿构建好的命令对象继续配置。
- `.complete()` = 构建 + 注册到父节点,并返回父节点,方便链式接着写兄弟命令。
- `.buildAndRegister()` 也是构建 + 注册,但返回的是**自己**(不是父节点)。
- `SubCommand.treeBuilder()` 出 `TreeSubCommand`(容器),`SubCommand.taskBuilder()` 出 `TaskSubCommand`(叶子)。

## 3. 参数定义(`SimpleCommandArgs.ArgumentBuilder`)

| 方法 | 说明 | 示例 |
|------|------|------|
| `.name(String)` | 参数名(Lombok fluent setter) | `.name("count")` |
| `.intValue()` | 整数,默认 tab 提示 | `.intValue()` |
| `.intValue(int def)` | 整数带默认值 | `.intValue(10)` |
| `.intValue(IntList list)` | 整数,限定候选值 | `.intValue(IntList.of(1,2,3))` |
| `.floatValue()` / `.floatValue(float def)` | 浮点数 | `.floatValue()` |
| `.bool()` / `.bool(boolean def)` | 布尔,tab 出 true/false | `.bool()` |
| `.select(String... list)` / `.select(List, String def)` | 固定选项 | `.select("a","b")` |
| `.enumValue(Class<E>)` / `.enumValue(E value)` | 枚举 | `.enumValue(MyEnum.class)` |
| `.tabSupplier(Supplier<Stream<String>>)` | 自定义 tab | `.tabSupplier(WorldUtils::getWaypointNames)` |
| `.tabCompletor(TabResult)` / `.tabCompletor(Function<CommandExecution, Stream<String>>)` | 更灵活的补全 | |
| `.defaultValue(String)` / `.defaultObject(T)` | 缺省值 | `.defaultValue("0")` |
| `.dispatchLast(...)` / `.dispatchLastArg(...)` | 依据已输入内容动态决定后面的补全 | |
| `.build()` | 产出 `ArgumentType` | |

自定义参数类型通过工厂方法传入:

```java
SimpleCommandArgs.argumentBuilder(MovTasks.TpaAndPosArgumentType::new).name("target").build()
SimpleCommandArgs.argumentBuilder(PosArgumentType::new).name("position").build()
```

同一路径下要写多个参数,就连续调 `.arg(...)`;每个参数各写一个 `argumentBuilder()`。

## 4. 参数读取(`ArgumentInputStream`)

```java
private boolean onSomeCommand(CommandExecution exec, ArgumentInputStream args, ArgumentReader reader) {
    int i = args.nextInt();
    double d = args.nextDouble();
    float f = args.nextFloat();
    boolean b = args.nextBoolean();
    String s = args.nextNonnullString();
    MyEnum e = args.nextEnum(MyEnum.class);
    String selected = args.nextSelect(List.of("a", "b"));
    Object opt = args.nextArg();                    // 可空
    int clamped = args.nextClampedInt(0, 100);
    double cd = args.nextClampedDouble(0.0, 1.0);
    float cf = args.nextClampedFloat(0f, 1f);
    Object orDefault = args.nextArgOrDefault(() -> fallback);

    // 游标操作
    InputArgument<?> peeked = args.peekNext();
    boolean more = args.hasNext();

    return true;
}
```

- 返回类型不确定时用 `<T> T nextArg()` 让调用点推断。
- `reader`(第三个参数)是原始字符串游标:`hasNext()` / `peek()` / `next()` /
  `getAlreadyReadArgStr()` / `getRemainingArgs()` / `stepAll()`。

## 5. 命令执行体(`CommandContext`)

`TaskSubCommand.executor(...)` 需要一个 `CommandContext`。直接用 lambda 写三参数版本:

```java
.post(e -> e.executor(this::onTravelTo))

private boolean onTravelTo(CommandExecution exec, ArgumentInputStream args, ArgumentReader reader) {
    return true;   // 返回 false 表示"这个命令没处理",框架会走失败流程
}
```

或者用现成工厂:

| 工厂 | 签名 | 说明 |
|------|------|------|
| `CommandContext.run(Runnable)` | 无参 | 直接跑 |
| `CommandContext.run(BooleanSupplier)` | 无参 | 返回 boolean |
| `CommandContext.run(Consumer<ArgumentInputStream>)` | 参数流 | |
| `CommandContext.run(BiConsumer<Player, ArgumentInputStream>)` | 玩家 + 参数流 | 非玩家直接返回 false |
| `CommandContext.run(TriFunction<Player, ArgumentInputStream, ArgumentReader, Boolean>)` | 全量 | 非玩家直接返回 false |
| `CommandContext.execute(Consumer<CommandExecution>)` | 上下文 | 不看参数 |
| `CommandContext.execute(BiConsumer<CommandExecution, ArgumentInputStream>)` | 上下文 + 参数流 | |
| `CommandContext.execute(BiPredicate<CommandExecution, ArgumentInputStream>)` | 上下文 + 参数流 | 返回 boolean |

## 6. 执行上下文(`CommandExecution`)

| 方法 | 说明 |
|------|------|
| `getExecutor()` | 玩家或 null |
| `isPlayer()` | 是否玩家 |
| `getExecutorPlayer()` | 强制获取玩家,非玩家抛 `InvalidExecutorError` |
| `sendMessage(String)` | 发消息,支持 `&` 颜色码 |
| `sendMessage(Component)` | 发 Component |
| `hasPermission(String)` | 权限检查 |
| `getExecutePos()` | 执行位置(`Vector3d`) |
| `getExecuteEyePos()` | 执行眼睛位置 |
| `getExecuteRot()` | 执行朝向(`Vector2f`) |
| `getExecuteWorld()` | 执行所在世界(`Level`) |
| `CommandExecution.EMPTY` | 空实现 |
| `CommandExecution.sender(Player)` | 由玩家构造 |

## 7. 错误处理(内置异常,自动捕获并提示)

| 异常 | 触发 |
|------|------|
| `TypeError` | 类型不匹配 |
| `ValueAbsentError` | 缺少必需参数 |
| `ValueParseError` | 参数解析失败 |
| `ValueOutOfRangeError` | 数值超范围 |
| `InvalidExecutorError` | 玩家/控制台限制 |
| `PermissionDenyError` | 权限不足 |
| `LogicalError` | 自定义逻辑错误 |
| `DispatchFailureError` | 子命令分发失败(默认转成帮助) |

手动抛异常 / 断言:

```java
AbstractMainCommand.checkArgument(condition, "错误信息");
AbstractMainCommand.checkNonnull(obj, "不能为空");
throw new LogicalError("自定义错误");
permissionDenied("my.permission", reader);
checkPermission(sender, "my.permission", reader);
```

这些异常由 `AbstractMainCommand` 实现 `InterruptionHandler` 处理,通过 `sendMessage` 输出**中文**提示。

## 8. 完整模块内集成示例

```java
public class TpaCommand extends BaseModule {
    public TpaCommand() {
        super("TpaCommand");
    }

    @Override
    public void registerAll() {
        super.registerAll();
        registerCommandBootstrap(this::bootStrapTpaCommand);
    }

    public void bootStrapTpaCommand(MainCommand mainCommand) {
        TreeSubCommand main = mainCommand.mainBuilder().name("tpa").build();

        main.subBuilder(SubCommand.taskBuilder())
                .name("tp")
                .helper("message.command.tpa.tp.help")
                .arg(SimpleCommandArgs.argumentBuilder(PosArgumentType::new)
                        .name("position")
                        .build())
                .post(e -> e.executor(this::onTp))
                .complete();

        main.subBuilder(SubCommand.taskBuilder())
                .name("mark")
                .helper("message.command.tpa.mark.help")
                .arg(SimpleCommandArgs.argumentBuilder()
                        .name("type")
                        .select(List.of("player", "camera", "this", "pos", "target", "cross", "clear"), "camera")
                        .build())
                .post(e -> e.executor(this::onMark))
                .complete();
    }

    public boolean onTp(CommandExecution p, ArgumentInputStream re, ArgumentReader reader) {
        ExecutePos pos = re.nextArg();
        if (pos == null) {
            p.sendMessage("输入了无效坐标!");
            return true;
        }
        Vector3d target = pos.getPosition(p);
        MovTasks.executeTp(new Vec3(target.x, target.y, target.z), 320, true, true);
        return true;
    }
}
```

## 9. 常见错误

- ❌ 在 `registerAll()` 之外调 `registerCommandBootstrap` → bootstrap 不会随模块生命周期注销
- ❌ 忘了 `.complete()` → 子命令没被注册到父节点
- ❌ 用 `.build()` 建完就以为注册好了 → `build()` 只构建,`complete()` / `buildAndRegister()` 才注册
- ❌ 参数顺序与 `.arg(...)` 声明顺序不一致 → `ArgumentInputStream` 严格按声明顺序读取
- ❌ `helper` 里直接写中文 → 应写语言 key(如 `message.command.tpa.tp.help`)
- ❌ 直接把 `reader.next()` 当强类型用 → 类型转换走 `ArgumentInputStream`
