# Minecraft 实体运动系统文档（26.2 / mojmap）

> 本文梳理的是 **Minecraft 原版**的实体运动机制，不是本项目 API。
> 类名与方法名以 **26.2 mojmap** 为准（本文所有签名都用官方 jar 的 `javap` 核对过）。
> 写跨版本代码前先看 `多版本工程.md`。

## 1. 运动基础：`Entity`

`Entity` 是所有实体的基类，定义最基础的位置、速度、移动与碰撞。

### 1.1 位置与速度

| 内容 | 26.2 API | 说明 |
|---|---|---|
| 位置 | `position()` → `Vec3` | 只读；改位置用 `setPos` |
| 设位置 | `setPos(Vec3)` / `setPos(double,double,double)` | `setPosRaw(...)` 跳过部分校验（加载/传送时用） |
| 上一 tick 位置 | `oldPosition()` → `Vec3` | 渲染插值用 |
| 速度 | `getDeltaMovement()` / `setDeltaMovement(...)` / `addDeltaMovement(Vec3)` | **不是 `getVelocity`** |
| 是否落地 | `onGround()` / `setOnGround(boolean)` / `setOnGroundWithMovement(boolean, Vec3)` | |
| 碰撞标志 | `horizontalCollision` / `verticalCollision` / `verticalCollisionBelow` / `minorHorizontalCollision` | 都是 **public 字段**，直接读 |
| 重力 | `getGravity()`（`final`） | 子类重写 `getDefaultGravity()` |
| 坐标 | `blockPosition()` / `chunkPosition()` | |
| 无碰撞 | `noPhysics`（public 字段） | 为 `true` 时 `move` 直接位移，不做碰撞求解 |

### 1.2 移动流程：`move`

```java
public void move(MoverType type, Vec3 movement)
```

`MoverType` 只有 5 个值：`SELF`（自身物理）、`PLAYER`（玩家输入）、`PISTON`、`SHULKER_BOX`、`SHULKER`。

流程：

1. `noPhysics == true` → 直接 `setPos(position().add(movement))`，跳过下面全部
2. 活塞/潜影盒推动的位置调整
3. 碰撞求解（见下）
4. 更新位置、写碰撞标志（`horizontalCollision` / `verticalCollision` / `onGround`）
5. 落地处理、脚步声等

碰撞求解链路：

```
Entity.collide(Vec3)                    // private，实体自身的碰撞入口
  └─ Entity.collideBoundingBox(...)      // public static
       ├─ collectAllColliders(...)        // 收集 VoxelShape（含世界边界）
       └─ collideWithShapes(...)          // 逐轴推进，得出实际可位移量
```

### 1.3 输入 → 速度

- `Entity.moveRelative(float speed, Vec3 input)`：按当前朝向把输入向量转成世界坐标的加速度，**加到** `deltaMovement` 上
- `Entity.push(Vec3)` / `push(double,double,double)` / `push(Entity)`：外力（挤压、击退等）

### 1.4 重力在哪应用

`baseTick()` **不**直接加重力。重力在 `travel*` 系列里通过 `LivingEntity.getEffectiveGravity()`
（会考虑缓慢下落效果）扣除 —— 见 2.2。

## 2. 生物运动：`LivingEntity`

### 2.1 入口：`travel(Vec3 input)`

```java
public void travel(final Vec3 input) {
    if (this.shouldTravelInFluid(this.level().getFluidState(this.blockPosition()))) {
        this.travelInFluid(input);
    } else if (this.isFallFlying()) {
        this.travelFallFlying(input);
    } else {
        this.travelInAir(input);
    }
}
```

| 分支 | 方法 | 进入条件 |
|---|---|---|
| 流体 | `travelInFluid` → `travelInWater` / `travelInLava` | `shouldTravelInFluid`：在水中或岩浆、`isAffectedByFluids()`、且不能站在流体上 |
| 滑翔 | `travelFallFlying(Vec3)`（private） | `isFallFlying()`（装备鞘翅且在下落） |
| 其它 | `travelInAir(Vec3)`（private） | 标准地面 / 空中运动 |

另外 `travelFlying(input, speed)` 是**会飞的生物**用的分支（`Allay` / `Ghast` / `Phantom` 等自己重写 `travel` 时调用）。
`Player` **不**走它 —— 见 §3。

### 2.2 标准运动：`travelInAir`

```java
private void travelInAir(final Vec3 input) {
    BlockPos posBelow = this.getBlockPosBelowThatAffectsMyMovement();
    float blockFriction = this.onGround()
        ? computeModifiedFriction(this.level().getBlockState(posBelow).getBlock().getFriction(),
                                  (float) this.getAttributeValue(Attributes.FRICTION_MODIFIER))
        : 1.0F;
    Vec3 movement = this.handleRelativeFrictionAndCalculateMovement(input, blockFriction);
    double movementY = movement.y;
    MobEffectInstance levitation = this.getEffect(MobEffects.LEVITATION);
    if (levitation != null) {
        movementY += (0.05 * (levitation.getAmplifier() + 1) - movement.y) * 0.2;
    } else if (...) {
        movementY -= this.getEffectiveGravity();
    }
    // 最后乘阻力（水平 = blockFriction * 0.91，垂直 = 0.98）
}
```

要点：

- **摩擦力来自脚下方块**的 `getFriction()`，再经 `Attributes.FRICTION_MODIFIER` 修正；在空中恒为 `1.0`
- **飘浮（`MobEffects.LEVITATION`）优先于重力**
- 收尾乘阻力：水平 `blockFriction × 0.91`、垂直 `0.98`，两者都受 `Attributes.AIR_DRAG_MODIFIER` 影响；
  若 `shouldDiscardFriction()` 为真则**不乘**，直接采用

核心步进 `handleRelativeFrictionAndCalculateMovement(Vec3 input, float friction)`：

```java
this.moveRelative(this.getFrictionInfluencedSpeed(friction), input);
this.setDeltaMovement(this.handleOnClimbable(this.getDeltaMovement()));
this.move(MoverType.SELF, this.getDeltaMovement());
Vec3 movement = this.getDeltaMovement();
if ((this.horizontalCollision || this.jumping) && (this.onClimbable() || /* 粉雪 */)) {
    movement = new Vec3(movement.x, 0.2, movement.z);   // 梯子/藤蔓/粉雪上往上带一点
}
return movement;
```

- `getFrictionInfluencedSpeed(friction)`：**在地面**且 `friction > 0.6` 时按 `0.216 / friction³` 缩放 `getSpeed()`；
  **在空中**用 `getFlyingSpeed()` —— 这条就是创造飞行能"飘"起来的原因
- `handleOnClimbable(delta)`：攀爬时把速度夹到 `0.15` 以内（水平 ±0.15、垂直不低于 -0.15）；
  按住潜行且在梯子上时不下滑

### 2.3 流体运动：`travelInFluid`

```
travelInFluid(Vec3)
  ├─ isInWater() → travelInWater(input, baseGravity, isFalling, oldY) → floatInWaterWhileRidden()
  └─ else        → travelInLava(input, baseGravity, isFalling, oldY)
```

- 水中减速：`isSprinting() ? 0.9F : getWaterSlowDown()`（后者默认 `0.8`）
- 水中基础加速度 `0.02F`，受 `Attributes.WATER_MOVEMENT_EFFICIENCY` 放大（离地时减半）
- 阻力：水 `×0.8`、岩浆 `×0.5`
- `getFluidFallingAdjustedMovement(baseGravity, isFalling, movement)`：处理下沉 / 浮力平衡
  （冲刺时不生效）

### 2.4 滑翔：`travelFallFlying`

装备鞘翅且 `isFallFlying()` 时进入（private 方法）。按俯仰角换算滑翔速度并禁用常规重力。
相关判定：`canGlide()`、`canGlideUsing(ItemStack, EquipmentSlot)`。
`Player` 重写了 `canGlide()`：**飞行时不允许滑翔**。

### 2.5 跳跃

```java
public void jumpFromGround() {
    float jumpPower = this.getJumpPower();
    if (!(jumpPower <= 1.0E-5F)) {
        Vec3 movement = this.getDeltaMovement();
        this.setDeltaMovement(movement.x, Math.max(jumpPower, movement.y), movement.z);
        if (this.isSprinting()) {
            float angle = this.getYRot() * 0.017453292F;
            this.addDeltaMovement(new Vec3(-Mth.sin(angle) * 0.2, 0.0, Mth.cos(angle) * 0.2));
        }
        this.needsSync = true;
    }
}

protected float getJumpPower(final float multiplier) {
    return (float) this.getAttributeValue(Attributes.JUMP_STRENGTH) * multiplier
         * this.getBlockJumpFactor() + this.getJumpBoostPower();
}
```

- 跳跃强度 = `Attributes.JUMP_STRENGTH` × **脚下方块的跳跃因子** `getBlockJumpFactor()` + 跳跃提升加成
- **冲刺时额外给一个沿朝向的水平推力**（`addDeltaMovement`），这是"冲刺跳"更远的原因
- 流体里的"跳"是 `jumpInLiquid(TagKey<Fluid>)`

### 2.6 攀爬

- `onClimbable()`：是否在可攀爬物上（梯子 / 藤蔓 / 脚手架等），并用 `getLastClimbablePos()` 记住位置
- 速度限制在 `handleOnClimbable(delta)` 里做（见 2.2）
- `(horizontalCollision || jumping)` 时垂直速度被抬到 `0.2`

### 2.7 属性（`Attributes`）

| 属性 | 作用 |
|---|---|
| `MOVEMENT_SPEED` | 基础移动速度（`getSpeed()` 的来源） |
| `JUMP_STRENGTH` | 跳跃强度 |
| `GRAVITY` | 重力 |
| `SAFE_FALL_DISTANCE` | 安全下落距离 |
| `FALL_DAMAGE_MULTIPLIER` | 摔落伤害倍率 |
| `STEP_HEIGHT` | 自动上台阶高度 |
| `WATER_MOVEMENT_EFFICIENCY` | 水中移动效率 |
| `MOVEMENT_EFFICIENCY` | 速度乘数（雪地等） |
| `FLYING_SPEED` | 飞行速度 |
| `SCALE` | 体型缩放（影响碰撞箱） |
| `FRICTION_MODIFIER` | **26.2 新增**：方块摩擦修正 |
| `AIR_DRAG_MODIFIER` | **26.2 新增**：空气阻力修正 |

### 2.8 每 tick 入口

- `LivingEntity.aiStep()` —— **不是 `tickMovement`**：处理输入衰减、跳跃、滑翔、挤压伤害等
- `LivingEntity.tick()` → `baseTick()` → `aiStep()`
- `getSpeed()` / `setSpeed(float)`：控制（AI）移动速度，`getFrictionInfluencedSpeed` 会读它

## 3. 玩家运动：`Player` / `LocalPlayer`

`Player.travel(Vec3)` 的重写逻辑（**注意不是走 `travelFlying`**）：

```java
@Override
public void travel(final Vec3 input) {
    if (this.isPassenger()) {
        super.travel(input);                 // 骑乘时完全交给坐骑那套
    } else {
        if (this.isSwimming()) {             // 游泳：按视线俯仰角给垂直加速
            double lookAngleY = this.getLookAngle().y;
            double multiplier = lookAngleY < -0.2 ? 0.085 : 0.06;
            if (lookAngleY <= 0.0 || this.jumping || /* 头顶有水 */) {
                Vec3 movement = this.getDeltaMovement();
                this.setDeltaMovement(movement.add(0.0, (lookAngleY - movement.y) * multiplier, 0.0));
            }
        }
        if (this.getAbilities().flying) {    // 飞行：先走父类，再把 Y 衰减到 0.6
            double originalMovementY = this.getDeltaMovement().y;
            super.travel(input);
            this.setDeltaMovement(this.getDeltaMovement().with(Direction.Axis.Y, originalMovementY * 0.6));
        } else {
            super.travel(input);
        }
    }
}
```

- **飞行**：状态在 `getAbilities()` 里（`Abilities.flying` / `mayfly` / `getFlyingSpeed()`）；
  水平速度靠 §2.2 里"空中用 `getFlyingSpeed()`"这条实现，再叠加这里对 Y 的 `×0.6` 阻尼
- **冲刺**：`isSprinting()` / `setSprinting(boolean)`；跳跃时的额外推力见 §2.5
- **游泳**：`isSwimming()`；`updateSwimming()` 在飞行时会强制关掉游泳状态
- **骑乘**：`travelRidden(Player, Vec3)`（private）+ `getRiddenInput(Player, Vec3)` /
  `getRiddenSpeed(Player)` / `tickRidden(Player, Vec3)`（都是 protected，坐骑子类重写）

### 客户端预测（`LocalPlayer`）

- `LocalPlayer.aiStep()`：按本地输入更新位置（本地预测）
- `sendPosition()`：把位置/旋转变化打包成 `ServerboundMovePlayerPacket` 发出
  —— 只在变化超过阈值或间隔够久时才发完整包
- `sendIsSprintingIfNeeded()`：冲刺状态单独同步
- **自动跳跃**：`isAutoJumpEnabled()` / `canAutoJump()`，由射线检测与碰撞箱决定是否起跳

## 4. 运动状态机

状态在 `aiStep()` / `travel()` 中按条件切换：

| 状态 | 判定（26.2） | 行为 |
|---|---|---|
| 在流体中 | `isInWater()` / `isInLava()` + `isAffectedByFluids()` | 走 `travelInFluid`，阻力大、有浮力 |
| 滑翔 | `isFallFlying()` | 走 `travelFallFlying`，按俯仰角改变速度 |
| 攀爬 | `onClimbable()` | 速度夹到 0.15，可上下移动 |
| 潜行 | `isShiftKeyDown()` / 姿态 `Pose.CROUCHING` | 降速、防掉落边缘 |
| 飞行 | `getAbilities().flying` | Y 阻尼 0.6、无重力、可自由升降 |
| 骑乘 | `isPassenger()` | 由 `travelRidden` / 坐骑控制 |
| 睡觉 | `isSleeping()` | 不移动 |

## 5. 运动相关数据同步

**服务端**

- `LivingEntity` 用 `sendEquipmentChanges()` 之类同步装备，但**不逐 tick 发位置**
- 位置同步由 **`ChunkMap.TrackedEntity`** 负责（旧 Yarn 名 `EntityTrackerEntry`）：按可见范围定期下发
- 玩家移动包：`ServerGamePacketListenerImpl.handleMovePlayer(ServerboundMovePlayerPacket)`
  → 校验 → `Player.move(MoverType.PLAYER, ...)` → 更新服务端位置 → 广播给附近玩家

**客户端**

| 场景 | 包 | 处理入口 |
|---|---|---|
| 实体首次出现 | `ClientboundAddEntityPacket` | `ClientPacketListener.handleAddEntity` |
| 增量移动 | `ClientboundMoveEntityPacket`（`.Pos` / `.Rot` / `.PosRot`） | `handleMoveEntity` |
| 强制位置同步 | `ClientboundEntityPositionSyncPacket` | `handleEntityPositionSync` |
| 传送 | `ClientboundTeleportEntityPacket` | `handleTeleportEntity` |

- `ClientboundMoveEntityPacket` 的坐标是 **short 量化**的（`xa/ya/za`），所以是"增量"
- **平滑插值**由 `InterpolationHandler` 负责：`interpolateTo(Vec3, float, float)` /
  `interpolate()` / `hasActiveInterpolation()` / `cancel()`，
  插值步数默认 `InterpolationHandler.DEFAULT_INTERPOLATION_STEPS`

## 6. 关键代码路径总结

```
玩家输入 → LocalPlayer.aiStep() → 更新 input → travel(Vec3)
        → handleRelativeFrictionAndCalculateMovement(input, friction)
            ├─ moveRelative(getFrictionInfluencedSpeed(friction), input)
            ├─ handleOnClimbable(deltaMovement)
            └─ move(MoverType.SELF, deltaMovement)
        → 更新本地位置 → sendPosition() → ServerboundMovePlayerPacket

服务端   → ServerGamePacketListenerImpl.handleMovePlayer(...)
        → 校验 → Player.move(MoverType.PLAYER, ...) → 碰撞 → 更新服务端位置
        → ChunkMap.TrackedEntity 广播给附近玩家

AI 生物  → Mob.aiStep() → ... → travel(...) → 移动 → 导航更新

碰撞     → Entity.move(MoverType, Vec3) → collide(Vec3) → collideBoundingBox(...)
        → 逐轴推进 VoxelShape → 写 horizontalCollision / verticalCollision / onGround
```

核心思想：**所有位移都走统一的 `move()` 做碰撞**；派生类通过重写 `travel()` 换不同环境的物理；
数值调参走**属性系统**（`Attributes`）而不是硬编码。
