# Minecraft 实体运动系统文档

本文件梳理 **26.1.2 / 26.2**(mojmap)中实体运动的整体结构、关键方法与时序。
类名全部为 mojmap 官方名,**与 yarn 版本差异很大**,对照见文末附录。

> 两版的差异集中在**摩擦与空气阻力**和**弹性**上,正文里已用「**26.2 才有**」标出;
> 其余方法(分派、流体、鞘翅、玩家飞行、客户端预测)两版一致。

- `net.minecraft.world.entity.Entity`
- `net.minecraft.world.entity.LivingEntity`
- `net.minecraft.world.entity.player.Player`
- `net.minecraft.client.player.LocalPlayer`

## 1. Entity:位置、速度、重力

| 成员 | 说明 |
|------|------|
| `position()` | 当前坐标(`Vec3`) |
| `setPos(double, double, double)` / `setPos(Vec3)` | 直接设置坐标(同时刷新 `xo/yo/zo` 等) |
| `getX()` / `getY()` / `getZ()` | 单轴坐标 |
| `xo` / `yo` / `zo` | 上一 tick 坐标,用于插值渲染 |
| `getDeltaMovement()` | 速度(`Vec3`) |
| `setDeltaMovement(double, double, double)` / `setDeltaMovement(Vec3)` | 设置速度 |
| `getGravity()` | `public final`;`isNoGravity()` 时返回 0,否则委托 `getDefaultGravity()` |
| `getDefaultGravity()` | `Entity` 返回 0;`LivingEntity` 返回 `Attributes.GRAVITY` 属性值 |
| `getEffectiveGravity()` | `LivingEntity` 覆写:下落中且带缓慢下落效果时取 `min(gravity, 0.01)` |
| `applyGravity()` | 把 `-gravity` 加到速度的 Y 分量上 |
| `getAirDrag()` | `Entity` 默认 0.98;`LivingEntity` 用 `AIR_DRAG_MODIFIER` 属性修正 |
| `onGround()` / `setOnGroundWithMovement(...)` | 落地状态 |
| `horizontalCollision` / `verticalCollision` / `verticalCollisionBelow` | 碰撞标志 |
| `isInWater()` / `isInLava()` / `getFluidHeight(TagKey<Fluid>)` | 流体状态 |

### 1.1 核心移动方法 `move(MoverType, Vec3)`

```java
public void move(MoverType moverType, Vec3 delta) {
    if (this.noPhysics) {
        // 无碰撞:直接位移,清空所有碰撞标志
    } else {
        if (moverType == MoverType.PISTON) {
            delta = this.limitPistonMovement(delta);   // 活塞推挤限制
            if (delta.equals(Vec3.ZERO)) return;
        }
        if (this.stuckSpeedMultiplier.lengthSqr() > 1.0E-7) {   // 卡在方块里
            if (moverType != MoverType.PISTON) delta = delta.multiply(this.stuckSpeedMultiplier);
            this.stuckSpeedMultiplier = Vec3.ZERO;
            this.setDeltaMovement(Vec3.ZERO);
        }
        delta = this.maybeBackOffFromEdge(delta, moverType);    // 潜行防掉边缘等
        Vec3 movement = this.collide(delta);                    // 实际可移动量
        // ... 位移、记录 Entity.Movement
        // 统计 x/z 碰撞 → horizontalCollision
        // 统计 y 碰撞 → verticalCollision / verticalCollisionBelow / setOnGroundWithMovement
        // checkFallDamage / restituteMovementAfterCollisions(弹跳)
        // 最后按 getBlockSpeedFactor() 衰减水平速度
    }
}
```

要点:

- 位移前会做 **边缘回退**(`maybeBackOffFromEdge`)、**卡位限制**、**活塞限制**。
- 碰撞结果写入 `horizontalCollision` / `verticalCollision` / `minorHorizontalCollision`。
- **26.2 才有**弹性(restitution)逻辑:`restituteMovementAfterCollisions` 会结合
  `getEntityBounciness()`、`Attributes.BOUNCINESS` 与方块自身的 `getBounceRestitution()`
   (史莱姆方块等)反弹速度,并发出 `GameEvent.BOUNCE`。26.1.2 的 `move` 里没有这一段。
- 结尾按 `getBlockSpeedFactor()`(灵魂沙、蜂蜜块等)对水平速度再乘一次系数。

`MoverType` 取值:`SELF` / `PLAYER` / `PISTON` / `SHULKER_BOX` / `SHULKER`。

> 旧 yarn 名 `MovementType` 就是现在的 `MoverType`。

### 1.2 碰撞计算

- `collide(Vec3 movement)`:基于自身包围盒在世界上做扫掠,返回真正能走的位移。
- 静态工具 `collideBoundingBox(...)` / `collideWithShapes(...)` 供特殊场景复用。

## 2. LivingEntity:`travel` 分派

```java
public void travel(Vec3 input) {
    if (this.shouldTravelInFluid(this.level().getFluidState(this.blockPosition()))) {
        this.travelInFluid(input);
    } else if (this.isFallFlying()) {
        this.travelFallFlying(input);
    } else {
        this.travelInAir(input);
    }
}
```

`shouldTravelInFluid(fluidState)` = `(isInWater() || isInLava()) && isAffectedByFluids() && !canStandOnFluid(fluidState)`。

### 2.1 空中 / 地面:`travelInAir(Vec3)`

```java
// 下面是 26.2 的写法
private void travelInAir(Vec3 input) {
    BlockPos posBelow = this.getBlockPosBelowThatAffectsMyMovement();
    float blockFriction = this.onGround()
            ? computeModifiedFriction(this.level().getBlockState(posBelow).getBlock().getFriction(),
                                      (float) this.getAttributeValue(Attributes.FRICTION_MODIFIER))
            : 1.0F;

    Vec3 movement = this.handleRelativeFrictionAndCalculateMovement(input, blockFriction);
    double movementY = movement.y;

    MobEffectInstance levitationEffect = this.getEffect(MobEffects.LEVITATION);
    if (levitationEffect != null) {
        movementY += (0.05 * (levitationEffect.getAmplifier() + 1) - movement.y) * 0.2;   // 飘浮
    } else if (!this.level().isClientSide() || this.level().hasChunkAt(posBelow)) {
        movementY -= this.getEffectiveGravity();                                          // 重力
    } else if (this.getY() > this.level().getMinY()) {
        movementY = -0.1;                                                                 // 区块未加载
    } else {
        movementY = 0.0;
    }

    if (this.shouldDiscardFriction()) {
        this.setDeltaMovement(movement.x, movementY, movement.z);
    } else {
        float airDrag = computeModifiedFriction(0.91F, (float) this.getAttributeValue(Attributes.AIR_DRAG_MODIFIER));
        float friction = blockFriction * airDrag;
        float verticalFriction =
                this.omnidirectionalAirMover() ? airDrag : computeModifiedFriction(0.98F,
                        (float) this.getAttributeValue(Attributes.AIR_DRAG_MODIFIER));
        this.setDeltaMovement(movement.x * friction, movementY * verticalFriction, movement.z * friction);
    }
}
```

- 水平摩擦 = 方块摩擦 × 空气阻力 **0.91**;垂直阻力默认 **0.98**。
- 重力在 `travelInAir` 里显式扣除(不是 `baseTick`)。
- `handleRelativeFrictionAndCalculateMovement` 内部:`moveRelative` →
  `handleOnClimbable`(攀爬限速) → `move(MoverType.SELF, ...) → 攀爬/细雪碰撞时抬升 Y。
- **26.1.2 的 `travelInAir` 不一样**:没有属性修正,直接
  `float friction = blockFriction * 0.91F;`,垂直阻力是
  `this instanceof FlyingAnimal ? friction : 0.98F`,也没有 `omnidirectionalAirMover()`。
  上面代码里的 `computeModifiedFriction(...)` 与 `AIR_DRAG_MODIFIER` / `FRICTION_MODIFIER` 都是 26.2 才有的。

### 2.2 流体:`travelInFluid` → `travelInWater` / `travelInLava`

- 先在岸边记录 `oldY` 与基础重力 `baseGravity`。
- 水中:基础速度 0.02,冲刺时阻力取 0.9;`WATER_MOVEMENT_EFFICIENCY` 属性提升;海豚的恩惠把阻力改 0.96;
  水平乘 `slowDown`、垂直乘 **0.8**,再经 `getFluidFallingAdjustedMovement` 修正。
- 岩浆中:盲速 0.02,速度整体乘 **0.5**(浅岩浆水平 0.5、垂直 0.8),最后额外扣 `-baseGravity / 4`。
- `jumpOutOfFluid(oldY)`:水平撞墙且上方有空间时给一个 0.3 的上跳(游泳出水)。
- `floatInWaterWhileRidden()`:可漂浮实体被骑乘时缓慢上浮。

### 2.3 鞘翅:`travelFallFlying(Vec3)`

```java
private void travelFallFlying(Vec3 input) {
    if (this.onClimbable()) {
        this.travelInAir(input);
        this.stopFallFlying();
    } else {
        Vec3 lastMovement = this.getDeltaMovement();
        double lastSpeed = lastMovement.horizontalDistance();
        this.setDeltaMovement(this.updateFallFlyingMovement(lastMovement));
        this.move(MoverType.SELF, this.getDeltaMovement());
        if (!this.level().isClientSide()) {
            this.handleFallFlyingCollisions(lastSpeed, this.getDeltaMovement().horizontalDistance());
        }
    }
}
```

`updateFallFlyingMovement` 按俯仰角算升力:先做重力补偿 `gravity * (-1 + cos²(xRot) * 0.75)`,
再按视线方向做加速/抬升,最后整体乘 `(0.99, 0.98, 0.99)`。

撞墙时 `handleFallFlyingCollisions` 按速度损失造成 `flyIntoWall` 伤害。

### 2.4 飞行:`travelFlying(Vec3, float)`

给"会飞的实体"用的通用实现:在水中 `moveRelative(0.02F)` + 乘 0.8;
岩浆 0.02 + 乘 0.5;空中按传入速度 + 乘 0.91。

### 2.5 被骑乘:`travelRidden` / `tickRidden` / `getRiddenInput` / `getRiddenSpeed`

`travelRidden(Player controller, Vec3 selfInput)` 把控制权交给坐骑:
`getRiddenInput` 拿输入 → `tickRidden` → 若 `canSimulateMovement()` 则 `travel(riddenInput)`,否则速度清零。

## 3. 跳跃、攀爬、滑翔

### 3.1 跳跃

```java
protected float getJumpPower() {          // 由 JUMP_STRENGTH 属性驱动
    return this.getJumpPower(1.0F);
}

public void jumpFromGround() {            // 注意:不是 jump()
    // 取跳跃力,叠加跳跃提升,设置速度 Y;冲刺时附加水平加速度
}
```

- 旧名 `jump()` 在 mojmap 里是 `jumpFromGround()`。
- 客户端自动跳跃在 `LocalPlayer` 中,靠射线与碰撞箱判断是否该起跳。

### 3.2 攀爬

- `onClimbable()`(旧 yarn `isClimbing()`)判断脚下是否梯子/藤蔓/脚手架等。
- `handleOnClimbable(Vec3)` 把水平速度钳制到 ±0.15、垂直下限 -0.15;
  手扶梯子下蹲(`isSuppressingSlidingDownLadder()`)时不下滑。

### 3.3 滑翔与游泳

- `isFallFlying()` / `updateFallFlying()` / `canGlide()` / `stopFallFlying()`。
- `Player.canGlide()` 额外要求 `!abilities.flying`。
- `isVisuallySwimming()` / `updateSwimAmount()` 控制游泳姿态。

## 5. Player 与 LocalPlayer

### 5.1 `Player.travel(Vec3)`

```java
public void travel(Vec3 input) {
    if (this.isPassenger()) {
        super.travel(input);
    } else {
        if (this.isSwimming()) {                       // 游泳时按视线方向推进
            double lookAngleY = this.getLookAngle().y;
            double multiplier = lookAngleY < -0.2 ? 0.085 : 0.06;
            if (lookAngleY <= 0.0 || this.jumping || !this.level()
                    .getFluidState(BlockPos.containing(this.getX(), this.getY() + 1.0 - 0.1, this.getZ())).isEmpty()) {
                Vec3 movement = this.getDeltaMovement();
                this.setDeltaMovement(movement.add(0.0, (lookAngleY - movement.y) * multiplier, 0.0));
            }
        }

        if (this.getAbilities().flying) {               // 飞行:垂直速度额外乘 0.6 衰减
            double originalMovementY = this.getDeltaMovement().y;
            super.travel(input);
            this.setDeltaMovement(this.getDeltaMovement().with(Direction.Axis.Y, originalMovementY * 0.6));
        } else {
            super.travel(input);
        }
    }
}
```

- `abilities.flying` 由 `Player.travel` 分支处理:飞行仍走 `super.travel`,但 Y 速度衰减 0.6。
- `abilities.mayfly` 时不受摔落伤害。
- `Player.updateSwimming()` 在飞行时强制 `setSwimming(false)`。

### 5.2 LocalPlayer 客户端预测

`LocalPlayer` 里客户端本地先算位置,再把差异发给服务器:

```java
private void sendPosition() {
    this.sendIsSprintingIfNeeded();                    // 冲刺状态变化单独发包
    if (this.isControlledCamera()) {
        double deltaX = this.getX() - this.xLast;
        double deltaY = this.getY() - this.yLast;
        double deltaZ = this.getZ() - this.zLast;
        double deltaYRot = this.getYRot() - this.yRotLast;
        double deltaXRot = this.getXRot() - this.xRotLast;
        this.positionReminder++;

        boolean move = Mth.lengthSquared(deltaX, deltaY, deltaZ) > Mth.square(2.0E-4)
                || this.positionReminder >= 20;        // 位移超阈值 或 满 20 tick 强制发
        boolean rot = deltaYRot != 0.0 || deltaXRot != 0.0;

        if (move && rot)      this.connection.send(new ServerboundMovePlayerPacket.PosRot(...));
        else if (move)        this.connection.send(new ServerboundMovePlayerPacket.Pos(...));
        else if (rot)         this.connection.send(new ServerboundMovePlayerPacket.Rot(...));
        else if (this.lastOnGround != this.onGround()
                || this.lastHorizontalCollision != this.horizontalCollision)
                              this.connection.send(new ServerboundMovePlayerPacket.StatusOnly(...));
    }
}
```

要点:

- 位移阈值是平方后的 `(2.0E-4)²`;即使完全没动,`positionReminder >= 20` 也会补一个包。
- 仅在落地状态/水平碰撞状态**变化**时才发 `StatusOnly`。
- 输入来自 `LocalPlayer.input`(`ClientInput`),由输入系统填充后再交给物理。
- `serverAiStep` / `aiStep` 负责客户端每 tick 的本地预测推进。

## 6. 服务端视角

- 客户端主动发 `ServerboundMovePlayerPacket`;服务端在 `ServerGamePacketListenerImpl`
  里校验并更新玩家位置,再通过实体追踪器广播给附近玩家。
- 其他实体的位置由服务端下发(`ClientboundAddEntityPacket` 生成 + 后续位置包),
  客户端做插值平滑。
- "是不是权威端"由 `isLocalInstanceAuthoritative()` 判断,
  只有权威端才会做摔落伤害与 `verticalCollision` 判定。

## 7. 与本模组的接口

需要在移动管线上做修改时,不要直接 Mixin `travel`,走 `LegalMovementManager`:

| 接入点 | 位置 |
|--------|------|
| `MovTasks.PLAYER_PIPELINE_0` | 唯一启用的修改管道 |
| `LegalMovementManager.MovementModifier` | 各阶段回调接口 |
| `LegalMovementManager.DelegateMovementModifier` | 可动态切换实现的包装器 |

对应事件通道(见 `事件.md`):`getPlayerTravelingTick()`、`getPlayerVelocityTick()`、
`getPlayerKeyboardInputTick()`、`getPlayerFallFlyingTick()`、`getPlayerSwitchFallFlying()`、
`getPlayerChangeLook()`、`getClientPlayerSendMovementPoint()`。
