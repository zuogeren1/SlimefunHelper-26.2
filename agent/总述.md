# 项目前情提要

本对话涉及一个名为 **SlimefunHelper** 的 Minecraft Fabric 模组开发框架。用户（模组开发者）提供了大量核心代码，并要求生成多个技术文档，以便后续的 AI Agent 能够理解并继续开发。

## 已提供的主要模块

1. **模块系统 (`BaseModule`)**
    - 所有功能模块的基类，支持配置（`FlagRef`、`IntRef`、`DoubleRef`、`EnumRef`、`KeyBindRef`）、生命周期（`onEnableModule`/`onDisableModule`）、事件监听、命令注册、热键绑定。
    - 配置通过 `Config` 存储，支持默认值、校验器、更新监听器。

2. **事件系统 (`Listener`, `RenderListener`)**
    - 提供了大量事件通道（`EventChannel`），包括游戏 tick、玩家行为、网络包、渲染、输入、实体、世界等。
    - 支持取消、修改、广播、按类型分发。
    - 示例：`postGameTick`、`attackAction`、`packetAcceptPoint`、`renderLayerTasks` 等。

3. **任务调度 (`Tasks`)**
    - 支持延迟任务、重复任务、基于 tick 的调度。
    - 提供 `scheduleDelayed`、`scheduleRepeated`、`scheduleTask` 等方法。

4. **命令系统 (`AbstractMainCommand`, `SubCommand`, `ArgumentInputStream`)**
    - 支持树形子命令、参数解析（整数、浮点数、布尔、枚举、选择）、自动补全、权限检查、错误处理。
    - 使用 `SimpleCommandArgs.ArgumentBuilder` 定义参数，通过 `ArgumentInputStream` 读取。

5. **GUI 组件库 (`DrawableWidget` 系列)**
    - 自绘组件：`SubScreenWidget`（容器）、`ScrollableListWidget`（滚动列表）、`ExecutableWidget`（可交互）、`SlotElement`（物品槽）、`IconElement`（图标按钮）、`ButtonElement`、`LabelElement` 等。
    - 渲染接口 `RenderHandler`，支持纹理、文本、物品、工具提示。
    - 事件处理接口 `ElementHandler`，支持点击、拖拽、键盘。
